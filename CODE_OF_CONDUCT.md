# Code of conduct

Netspeeder is a widget for KDE Plasma and follows the
[KDE Community Code of Conduct](https://kde.org/code-of-conduct/) in issues,
pull requests and everywhere else in this repository: be considerate,
respectful and collaborative.

Comments that break it may be edited, hidden or removed, and people who keep
breaking it may be blocked from the repository. To point out a problem, mention
@Flexomatic81 in an issue; if it should not be public, use
[Report a vulnerability](https://github.com/Flexomatic81/netspeeder/security/advisories/new)
under the Security tab, which only the maintainer sees.
